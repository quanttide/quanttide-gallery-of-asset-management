# 量潮平台资产类别

平台资产是量潮产品与服务的基础设施载体，分为 Git 仓库与 S3 存储桶两大类，遵循「类别明确、上架可控」的原则，禁止资产长期停留在未分类状态（如 `others` 分类）。

## 类别

平台资产按业务归属划分类别，类别以业务线前缀命名，如 `qtclass-`（量潮课堂）、`qtdata-`（量潮数据）、`qtcrowd-`（量潮众包）、`qtcloud-`（量潮云平台）等。

## Git 仓库

Git 仓库承载平台应用的源代码与配置，一个平台一个仓库，以平台名命名，如 `qtclass`（量潮课堂）。

## S3 存储桶

S3 存储桶承载平台的部署产物与业务数据，按 `{业务线前缀}-{桶类型}` 命名：

| 桶类型 | 命名 | 用途 | 示例 |
|:-------|:-----|:-----|:-----|
| Site 首页 | `{业务线}-site` | React 首页部署产物 | qtclass-site |
| Studio 工作台 | `{业务线}-studio` | Flutter 客户端部署产物 | qtclass-studio |
| Provider 平台数据 | `{业务线}-provider` | 平台维护的正式数据 | qtclass-provider |
| Private 内部数据 | `{业务线}-private` | 未上架的业务数据、备份 | qtclass-private |

业务数据上架时，从内部数据存储桶（`*-private`）转移到对应的平台数据存储桶（`*-provider`）。
